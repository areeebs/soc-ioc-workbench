# Security policy

This is a learning and analyst-assistance tool, not an automated verdict system. Review its output and the provider's terms before using it in an operational SOC.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository if enabled. Otherwise, contact the maintainer privately before sharing details publicly. Do not post real API keys, confidential indicators, customer data, or provider responses in an issue.

## Safe use

Only query indicators you are authorized to share. Local normalization stays offline. Provider lookup is an explicit user action and sends that one indicator to the selected third party.
